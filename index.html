Worksheet metadata

Mode

Final marking submits the whole paper at the end (the default flow). Practice mode lets the child mark up to the current page mid-paper, see what they got wrong, and continue. Pages are frozen once marked so the child can't go back and edit.

Most economical skips the strokes-only blank-detector signal; in practice mode you're marking ongoing work, so accuracy on the new pages matters most. Balanced is a reasonable default.

Advanced settings
API mode

Direct: browser calls api.openai.com directly with the API key below. Proxy: browser calls a Cloudflare Worker that holds the OpenAI key server-side (use this when the device's network blocks api.openai.com).

Worker code lives at relay/cloudflare-worker.js in the repo. Both values are kept only in this browser's localStorage; they are never committed.

Models per task

Different tasks have different economics. Each task can use its own model. Pricing is frozen per task at request time — historical reports keep their original prices.

Best quality: each page sent as one image plus a strokes-only companion. Highest accuracy. Most expensive.
Balanced: 4 pages packed into one image plus a strokes-only companion. Half the cost. Slightly less accurate on dense MCQ rows.
Most economical: 4 pages packed into one image, no strokes-only companion. Lowest cost. May miss some blank answers.

Cost estimate (verify against openai.com/api/pricing)
Custom prompt overrides (advanced — leave blank to use defaults)

Each textarea pre-fills with the built-in prompt from src/openai.js. Edit a textarea to override that prompt; click Reset to default to restore it. An unmodified textarea is automatically treated as "use the built-in" — future updates to the built-in prompt in the source flow through without needing a re-save.
